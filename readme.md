### 🎯 Project Objective

The goal of this project is to **design and implement automated tests** for the **web, mobile, and API flows** of the **Americanas** platform.  

The tests must validate **core user journeys**, such as:
- Registration  
- Login  
- Product search  
- Purchase flow  
- Wishlist management  

These validations ensure **functional consistency across interfaces and endpoints**.

---

### 🛠️ Technical Evaluation

The project assesses skills in:
- **Python**
- **Pytest**
- **Automation best practices**
- **Git flow**

It culminates in a **live demonstration** showcasing **stable and reliable test executions**.
